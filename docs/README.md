## Project Overview

ShopApp is a full-stack Enterprise Resource Planning (ERP) and management system designed for small to medium-sized businesses that need to integrate their sales, inventory, and financial processes.

### Key Features

1. Real-time inventory monitoring with intelligent alerts
2. Customer credit limit management with automatic transaction blocking
3. Automated financial reporting (P&L, cash flow, aging reports)
4. POS interface for quick order creation
5. PDF invoice generation and printing
6. Role-based access control and user management
